# עורך וידאו — Video Editor

כלי ווב אישי להכנת סרטוני שיווק לאפליקציות: חיתוך סרטונים, הוספת סגיר (outro),
ויצירה אוטומטית של כיתוב (caption) שיווקי באנגלית באמצעות Claude API.

## מה המערכת עושה

1. **אפליקציות (נכסים)** — מנהלים רשימת אפליקציות. לכל אפליקציה: שם, תיאור/אופי,
   לינק שיווקי, האשטאגים, וספריית סגירים משלה.
2. **עיבוד חדש** — בונים באצ' של בקשות. לכל בקשה: סרטון מקור (העלאת קובץ או
   לינק — כולל יוטיוב/טיקטוק דרך yt-dlp), שניית חיתוך, אפליקציה וסגיר.
   לחיצה אחת על "שלח לעיבוד" מריצה את כל הבאצ' ברקע.
3. **העיבוד** — הסרטון נשמר מההתחלה ועד שניית החיתוך, הסגיר מנורמל
   (רזולוציה/קצב פריימים/אודיו) ומשורשר מיד אחריו. מהקטע החתוך נשלפים פריימים
   שנשלחים ל-Claude יחד עם פרטי האפליקציה, ו-Claude מחזיר כיתוב שיווקי באנגלית
   עם hook לפי תוכן הסרטון, קריאה להורדה, הלינק וההאשטאגים.
4. **תוצאות** — סטטוס חי לכל בקשה, נגן וידאו, הורדת ה-mp4 והעתקת הכיתוב.
   התוצרים נשמרים גם אחרי הפעלה מחדש.

## דרישות מוקדמות

- Python 3.11+
- Node.js 18+
- **ffmpeg + ffprobe** זמינים ב-PATH:
  - Ubuntu/Debian: `sudo apt-get install -y ffmpeg`
  - macOS: `brew install ffmpeg`
- מפתח Anthropic API (אופציונלי — בלעדיו המערכת מייצרת כיתוב mock לבדיקות)

## התקנה

```bash
cp .env.example .env        # ערכו והכניסו ANTHROPIC_API_KEY

cd backend
python3 -m venv .venv && . .venv/bin/activate
pip install -r requirements.txt

cd ../frontend
npm install
```

## הרצה (פיתוח — שני טרמינלים)

```bash
# טרמינל 1 — backend
cd backend && . .venv/bin/activate
uvicorn app.main:app --reload --port 8000

# טרמינל 2 — frontend
cd frontend
npm run dev                 # http://localhost:5173 (מפנה /api ל-8000)
```

אפשר גם להריץ הכל משרת אחד: `cd frontend && npm run build` ואז ה-backend
יגיש את ה-UI ישירות מ-http://localhost:8000.

## משתני סביבה (`.env`)

| משתנה | ברירת מחדל | תיאור |
|---|---|---|
| `ANTHROPIC_API_KEY` | (ריק) | מפתח ה-API. ריק ⇒ כיתובי mock |
| `CLAUDE_MODEL` | `claude-sonnet-5` | המודל ליצירת כיתובים |
| `DATA_DIR` | `./data` | מיקום הקבצים וה-DB |
| `FFMPEG_WORKERS` | `2` | מספר סרטונים שמעובדים במקביל |
| `CAPTION_MOCK` | (ריק) | `1` ⇒ כיתובי mock גם עם מפתח |

## אחסון

הכל תחת `data/` (לא נכנס ל-git, בטוח לגבות או למחוק לאיפוס מלא):

```
data/app.db                    # SQLite — נכסים, סגירים, באצ'ים ובקשות
data/uploads/{request_id}/     # סרטוני מקור (העלאות והורדות)
data/outros/{asset_id}/        # קבצי הסגירים
data/outputs/{request_id}/     # final.mp4 — התוצרים המוכנים
data/frames/{request_id}/      # פריימים שנשלחו ל-Claude
```

## הערות

- כלי אישי לשימוש מקומי — אין אימות משתמשים; לא לחשוף לאינטרנט כמו שהוא.
- מקורות נתמכים: העלאת קובץ, לינק ישיר לקובץ וידאו, וכל אתר ש-yt-dlp תומך בו.
- כישלון של סרטון אחד בבאצ' לא עוצר את השאר; אם רק יצירת הכיתוב נכשלה,
  הווידאו נשמר ואפשר ללחוץ "צור כיתוב מחדש" מטאב התוצאות.
